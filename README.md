# Lost on a 600-Acre Campus
### Rethinking Lost and Found

## About the Project
Lost on a 600-Acre Campus is a web-based Lost and Found platform designed to help university students report lost items and notify others about items they have found on campus.

The main aim of this project is to make the lost-and-found process simpler, more organised, and accessible for students across a large university campus.

## Problem Statement
On a large university campus, students often face difficulties finding their lost belongings. Traditional methods of searching for lost items can be time-consuming and inconvenient.

This project proposes a simple digital platform where students can report lost and found items through separate forms.

## Key Features
- **Home Page:** Provides access to lost-item and found-item reporting.
- **Report Lost Item:** Students can enter item type, lost location, date, description, and contact number.
- **Report Found Item:** Students can provide details about found items and their location.
- **Confirmation Page:** Displays a confirmation message after form submission.
- **Responsive Design:** Designed to adapt to different screen sizes.
- **Simple Interface:** Easy-to-understand navigation and forms.
